## 完整 Prompt

创作一张日系时装插画：一位气质清冷但自然的年轻成年女性站在初秋午后的东京街角，微微回头，一手轻扶耳边发丝，另一手拎着简洁的手提包，正在街边橱窗前短暂停步。人物穿搭具有时尚杂志插画感：奶油白短款上衣，浅桃色或柔和杏色外套随意披着，下装使用大块深色来稳定画面（如深炭灰半裙或长裤），并加入一到两种鲜明强调色作为点缀（例如靛蓝、番茄红或明亮青绿色的小面积配饰）。

整体画风采用清晰、轻盈、粗细自然变化的深色线稿，外轮廓略重，五官、发丝和衣饰内部线条纤细。以干净的平涂色块和简练的赛璐璐阴影为主，只在必要处加入少量柔和过渡，保持二维手绘感。人物面部轮廓利落，眼睛精致而有神，上睫毛突出，眼周带少量粉红色；鼻子和嘴巴用极少的线条与色块概括，表情自然克制。头发按清晰的大束组织，辅以少量细发丝和短小高光，避免每根头发都刻画。皮肤以均匀底色为主，阴影简洁，不画强烈的体积渐变。亮面布料与少量金属饰品可加入少量锐利高光，与柔和哑光皮肤形成材质对比。

配色温暖、清透：奶油白和浅桃色作为柔和底色，用大块深色稳定画面。整体有时尚杂志插画的设计感，细节集中在眼睛、发型和少数精心选择的配饰，其余区域适当简化、留白。背景只保留简洁的东京街角元素，如橱窗、路牌、模糊建筑轮廓或几何形街景块面，避免繁复背景，让人物成为主体。画面精致但不堆砌装饰，保留轻松自然的手绘气息。

避免：写实摄影、3D渲染、油亮塑料皮肤、厚涂笔触、大面积空气刷渐变、过度唇妆、密集碎高光、繁复背景和自动添加的珠宝。
