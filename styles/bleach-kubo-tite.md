# 久保带人（BLEACH）视觉语言分析

> 目标：分析视觉语言，而不是简单复制作者名称。

## Visual Characteristics

### Line Art

- Clean sharp ink lines
- Strong silhouette design
- Minimal unnecessary details
- Fashion illustration influence

### Character Design

- Tall slim proportions
- Strong facial identity
- Modern street fashion
- Elegant poses

### Composition

- Cinematic framing
- Large empty space usage
- Strong contrast between characters and background
- Manga panel rhythm similar to storyboard shots

## Prompt Direction

Positive:

```
clean manga line art,
modern urban shonen manga character design,
fashion-forward costume,
elegant slim character silhouette,
sharp ink drawing,
high contrast black and white,
cinematic manga panel composition
```

Negative:

```
over detailed armor,
childlike proportions,
round cartoon face,
low contrast shading
```

## Notes

Future experiments should separate:

- ink style
- character design
- costume language
- panel composition

instead of using only artist name prompts.
